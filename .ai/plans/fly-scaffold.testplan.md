## 1. Goal

Scaffold of the CLI's main command (Linear **COINE-65**): the `mcfly` binary with the `fly`
subcommand becomes invocable end-to-end. `mcfly fly` prints exactly one of five fixed phrases,
chosen uniformly at random, on stdout and exits 0; every wrong invocation (no subcommand,
unknown subcommand, excess argument) fails on stderr with exit 1; `mcfly --help` prints the
commander-generated help. The command deliberately does nothing else — it is the first atomic
feature of the CLI and it materializes the Controller layer plus the injectable-randomness
seam that later features build on. A **Trip** (glossary, `CONTEXT.md`) is a single execution
of a Loop; the **Task** argument is explicitly out of scope here.

### 2.1 Behavioral decisions (frozen)

- **The five phrases** — exact texts, order is the selection order (index 0–4):
  1. `Warming up the time circuits...`
  2. `Roads? Where we're going, we don't need roads.`
  3. `Great Scott!`
  4. `The flux capacitor is fluxing.`
  5. `Setting destination time...`
- **Selection** — uniform, stateless: index = `Math.floor(value * FLY_PHRASES.length)` where
  `value` is the number returned by the injected `RandomSource`. No memory between Trips;
  consecutive repeats are legal. `runFly` consults the random source **exactly once** per call.
- **Fail fast on a broken RandomSource** — if the returned value is outside `[0, 1)` (including
  `NaN`), `runFly` throws a `RangeError` with the exact message
  `RandomSource returned <value>, expected [0, 1)`, where `<value>` is the returned number as
  JS stringifies it (so `1` → `RandomSource returned 1, expected [0, 1)`).
  The guard must be written so `NaN` fails it (i.e. test for NOT-in-range, not for in-range).
- **Program metadata** — `.name('mcfly')` set explicitly (the argv-derived default would leak
  the script filename under tsx/dist). Root description, frozen: `Deterministic orchestrator
  for multi-agent TDD loops` (same text as `package.json`). `fly` subcommand description,
  frozen: `Start a trip (scaffold, does nothing yet)`. **No** `.version()` — not in the
  COINE-65 contract (YAGNI).
- **Help pointer after errors** — `program.showHelpAfterError('(add --help for additional information)')`:
  this realizes the issue's "unknown command + pointer to `--help`" decision; commander does
  not add the pointer by default.
- **Excess argument** — `fly` declares no arguments; commander ≥13 rejects excess arguments by
  default (`error: too many arguments`), no extra configuration. The rejection is part of the
  contract (row 9).
- **Assert policy for commander-generated text** — usage/help/error texts are generated by
  commander: tests assert **exact-substring containment** of the contract markers
  (`Usage: mcfly`, `error: unknown command 'foo'`, `(add --help for additional information)`,
  `too many arguments`, the frozen descriptions) plus stream routing and exit codes — never
  the full formatted text (Test Philosophy: don't test the framework's formatting). Phrase
  output (row 5) is asserted by **exact equality** against the five literal texts.
- **CLI tests are subprocess e2e** — they spawn the real entrypoint with
  `process.execPath` + `--import tsx` on `src/main.ts` (no build step needed) and never
  import from `src/`. Rotation is *not* asserted statistically in e2e (flaky by design);
  determinism lives in the unit rows via the seam.
- **Not testable here, frozen for the implementation plan (verified in Phase 5):**
  `package.json` gains `"bin": { "mcfly": "dist/main.js" }`; dependency `commander@15.0.0`
  (approved in COINE-65; exact pin via `.npmrc` `save-exact`); shebang line in `src/main.ts`
  (preserved by `tsc` in `dist/`).
- **Lint trap** — `as const` is banned (`consistent-type-assertions: never`): `FLY_PHRASES`
  gets the explicit annotation `readonly string[]`, no assertion.

## 4. Mocks & Fixtures (allowed list)

- **May mock:** nothing. The `RandomSource` stubs in rows 2–4 (plain arrow functions with a
  fixed return value or a call counter) are the designed injection seam, not mocks of a
  boundary — allowed and required.
- **Must not mock:** `Math.random` (no global spy — determinism goes through the seam);
  `console.log` / `process.stdout` (row 5 asserts the real subprocess stdout); `execa` /
  `child_process` (rows 5–9 spawn the real entrypoint); commander internals.
- **Fixtures:** none. Two test-local helpers only: `runCli` (rows 5–9, shape above) and the
  local literal phrase array in `tests/main.test.ts` (row 5 — duplicated from §2.1 on purpose:
  the e2e file imports nothing from `src/`).
